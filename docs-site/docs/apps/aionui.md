Token。</li><li>添加或选择控制台可用模型名称。</li><li>返回聊天或代理页面，选择刚创建的模型测试。</li><li>到 KKRICH <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">使用日志</a> 确认请求记录。</li></ol><p>先从 KKRICH 令牌管理页复制 API
