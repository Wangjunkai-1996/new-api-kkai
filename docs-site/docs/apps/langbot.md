供应商，用于机器人对话和知识库向量化。</p><h2 id="下载和官方入口" tabindex="-1">下载和官方入口 <a class="header-anchor" href="#下载和官方入口" aria-label="Permalink to &quot;下载和官方入口&quot;">​</a></h2><table id="安装后检查" tabindex="-1">安装后检查 <a class="header-anchor" href="#安装后检查" aria-label="Permalink to &quot;安装后检查&quot;">​</a></h2><p>部署完成后先确认这几件事：</p><ol><li>LangBot 服务正在运行，并能进入 Web 管理后台，例如 Docker 默认本机地址 <code>127.0.0.1:5300</code>。</li><li>已创建或确认要使用的流水线。</li><li>已准备要绑定的机器人渠道账号，并确认渠道平台侧的机器人配置可用。</li><li>已在 KKRICH <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 创建 API Token。</li><li>已确认 KKRICH 聊天模型名称；如果要用知识库，也确认嵌入模型名称。</li></ol><h2 id="配置-kkrich" tabindex="-1">配置 KKRICH <a class="header-anchor" href="#配置-kkrich" aria-label="Permalink to &quot;配置 KKRICH&quot;">​</a></h2><p>先从 KKRICH 令牌管理页复制 API Key。建议为 LangBot 单独创建 Token，这样机器人消息、调试消息和知识库请求都能在使用日志中单独排查。</p><p><img src="/images/reference/apps-langbot-01.png" alt="从令牌管理页复制 LangBot API Key"></p><p>在 LangBot 管理后台添加模型，供应商选择 <code>NewAPI</code>，Base URL 填写 <code>https://api.kkrich.ltd/v1</code>，API Key 填写 KKRICH API Token。模型名称填写控制台可用的聊天模型名称。</p><p><img src="/images/reference/apps-langbot-02.png" alt="在 LangBot 中添加 KKRICH NewAPI 聊天模型"></p><p>模型保存后，进入流水线配置，把当前对话模型切换为刚添加的 KKRICH 模型。若有多条流水线，需要确认机器人实际绑定的是哪一条流水线。</p><p><img src="/images/reference/apps-langbot-03.png" alt="在 LangBot 流水线中选择 KKRICH 模型"></p><p>先在对话调试中发送测试消息。调试页能返回内容后，再进入渠道绑定，避免把模型配置问题误判为微信、飞书或其它渠道的问题。</p><p><img src="/images/reference/apps-langbot-04.png" alt="在 LangBot 对话调试中测试模型回复"></p><p>配置字段参考：</p><table tabindex="0"><thead><tr><th>LangBot 配置项</th><th>KKRICH 填写值</th><th>说明</th></tr></thead><tbody><tr><td>供应商</td><td>NewAPI</td><td>使用 OpenAI 兼容供应商。</td></tr><tr><td>Base URL / API 地址</td><td><code>https://api.kkrich.ltd/v1</code></td><td>固定使用 KKRICH OpenAI 兼容 Base URL。</td></tr><tr><td>API Key</td><td>KKRICH API Token</td><td>从 <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 复制，不要带多余空格。</td></tr><tr><td>聊天模型</td><td>KKRICH 控制台可用聊天模型名称</td><td>保存后在流水线中选择该模型。</td></tr><tr><td>嵌入模型</td><td>KKRICH 控制台可用嵌入模型名称</td><td>仅在使用知识库时配置。</td></tr></tbody></table><p>调试通过后，将机器人渠道绑定到使用 KKRICH 模型的流水线。绑定后可以在真实聊天窗口中发送消息，确认渠道消息能进入 LangBot，并由 KKRICH 模型生成回复。</p><p><img src="/images/reference/apps-langbot-05.png" alt="在真实渠道中测试 LangBot 机器人对话"></p><p>如果真实渠道无回复，优先检查三件事：渠道机器人是否在线、渠道是否绑定到正确流水线、流水线是否选择了 KKRICH 模型。只要对话调试可用，问题通常在渠道连接或绑定关系上。</p><h2 id="使用-langbot-知识库" tabindex="-1">使用 LangBot 知识库 <a class="header-anchor" href="#使用-langbot-知识库" aria-label="Permalink to &quot;使用 LangBot 知识库&quot;">​</a></h2><p>LangBot 的知识库需要嵌入模型把文档转成向量。你可以继续使用 NewAPI 供应商添加 KKRICH 嵌入模型，API 地址仍填写 <code>https://api.kkrich.ltd/v1</code>，API Key 使用同一个或单独的 KKRICH Token，模型名称填写控制台可用的嵌入模型。</p><p><img src="/images/reference/apps-langbot-06.png" alt="在 LangBot 中添加 KKRICH 嵌入模型"></p><p>新建知识库时，在向量模型或嵌入模型字段中选择刚添加的 KKRICH 嵌入模型。文档导入后，LangBot 会使用该模型完成向量化，后续机器人回复就可以结合知识库内容。</p><p><img src="/images/reference/apps-langbot-07.png" alt="新建知识库时选择 KKRICH 嵌入模型"></p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>LangBot 对话调试能收到模型回复。</li><li>绑定渠道能使用同一流水线回复。</li><li>知识库导入时能正常调用嵌入模型。</li><li>KKRICH <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">使用日志</a> 出现 LangBot 请求。</li><li>使用日志里的模型名称与 LangBot 流水线当前模型一致。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>机器人无回复：先在对话调试页验证模型，再检查渠道绑定。</li><li>渠道正常但模型失败：检查流水线是否选择了 KKRICH 模型。</li><li>渠道接不进来：检查对应平台的机器人凭据、回调地址、网络访问和事件订阅。</li><li>嵌入模型不可用：确认模型类型和知识库配置是否匹配。</li><li>认证失败：重新复制 KKRICH API Token，确认没有多余空格或换行。</li><li>日志无记录：检查 Base URL 是否为 <code>https://api.kkrich.ltd/v1</code>，并确认 Token 和流水线配置已保存。</li><li>知识库没有命中：确认文档已完成向量化，并检查机器人流水线是否启用了知识库能力。</li></ul><h2 id="下一步"
