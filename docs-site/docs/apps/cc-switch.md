确认请求已经到达。</li></ol><p>只有一键导入失败、Windows 无法唤起 CC Switch、或打开后没有生成 Provider 时，才手动新增 Provider。手动新增时，在对应应用页签中点击加号，填写名称、API Key、Base URL <code>https://api.kkrich.ltd/v1</code> 和模型名，保存后再启用。</p><h2
