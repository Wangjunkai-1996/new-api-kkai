AI 客户端或模型服务；新手要先安装 Claude Code，再用 CCR 把 Claude Code 的请求转发到 KKRICH。</p><p>如果你只是想最快跑通 Claude Code，先看 <a href="./claude-code">Claude Code</a> 的直接配置路线；如果你需要模型分流、协议适配、Web UI 或继续使用 <code>claude</code>
