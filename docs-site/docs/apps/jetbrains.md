href="#安装后检查" aria-label="Permalink to &quot;安装后检查&quot;">​</a></h2><ul><li>打开目标 IDE，进入 Settings 或 Preferences。</li><li>在 Plugins 中确认 AI Assistant 或其它 OpenAI 兼容插件已安装并启用。</li><li>在 KKRICH <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 创建 API Token。</li><li>在 KKRICH 控制台复制要用于 IDE 的模型名称。</li><li>记住：JetBrains IDE 不是 KKRICH 客户端，插件才是配置 KKRICH 的入口。</li></ul><h2 id="配置-kkrich" tabindex="-1">配置 KKRICH <a class="header-anchor" href="#配置-kkrich" aria-label="Permalink to &quot;配置 KKRICH&quot;">​</a></h2><p>以 JetBrains AI Assistant 为例，通常在 Settings 或 Preferences 的 Tools、AI Assistant、Providers &amp; API keys 中配置；第三方插件请进入它自己的 Provider、OpenAI 或 Custom Endpoint 设置。</p><ol><li>进入 AI 插件的 Provider、OpenAI Compatible 或 Custom Endpoint 设置。</li><li>Base URL 或 Endpoint 填写 <code>https://api.kkrich.ltd/v1</code>。</li><li>API Key 填写你的 KKRICH API Token。</li><li>模型名称填写 KKRICH 控制台可用模型名称。</li><li>如果插件要求分配模型，把该模型分配给 Chat、代码解释、补全或轻量任务。</li><li>保存后，在一个测试文件中执行解释代码、生成注释或聊天请求。</li></ol><p>不同 JetBrains 插件的字段名不同，但配置关系一致：Endpoint 或 Base URL 填 <code>https://api.kkrich.ltd/v1</code>，API Key 填 KKRICH Token，模型名称使用控制台可用模型。</p><p><img src="/images/feishu/feishu-07.png" alt="JetBrains 插件可按通用字段映射配置"></p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>找不到 KKRICH 配置入口：先确认 AI 插件已安装，IDE 本体不会单独提供 KKRICH 客户端入口。</li><li>当前插件不支持自定义网关：换用支持 OpenAI Compatible 的插件，或等待插件版本支持。</li><li>插件只支持补全不支持聊天：确认插件功能范围。</li><li>请求失败但无日志：请求可能未发送到 KKRICH，检查 Endpoint。</li><li>上下文过大：减少选中文件或关闭全仓库上下文。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a
