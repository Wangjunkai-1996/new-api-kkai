输出的端口、容器状态和防火墙。</li><li>Bot 无法执行：检查 Bot 容器或工作区是否创建成功、是否正在运行。</li><li>渠道能收到消息但无回复：检查渠道是否绑定到正确 Bot，并确认 Bot 已切换到 KKRICH 模型。</li><li>认证失败：重新复制 KKRICH API Token，确认没有多余空格或换行。</li><li>日志无记录：确认请求没有发到本地或其它 Provider，并检查当前 Bot 是否实际使用 KKRICH 模型。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>阅读 <a
