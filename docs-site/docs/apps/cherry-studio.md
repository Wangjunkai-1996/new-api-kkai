模型，发送一条简短消息测试回复。测试通过后，再把它保存到常用助手、提示词或工作区配置中。</p><p><img src="/images/reference/apps-cherry-studio-05.png" alt="切换到已添加的 KKRICH 聊天模型"></p><p>如需使用图像生成能力，先添加支持绘图的模型。绘图模型与聊天模型可以共用同一个 KKRICH Provider，但模型选择要分开处理：聊天页面选择聊天模型，绘图页面选择控制台中可用于图像生成的绘图模型。</p><p><img src="/images/reference/apps-cherry-studio-06.png" alt="添加支持绘图的 KKRICH
