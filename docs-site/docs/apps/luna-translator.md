&quot;配置 KKRICH&quot;">​</a></h2><p>推荐先用 KKRICH 控制台一键配置：</p><ol><li>在 KKRICH <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 选择要用于 Luna Translator 的 Token。</li><li>从应用菜单中选择 Luna Translator。</li><li>系统会尝试跳转到 Luna Translator，并自动写入 Base URL 与 API Key。</li><li>进入 Luna Translator 的 <code>设置</code>、<code>翻译设置</code>、<code>大模型</code>。</li><li>检查新增接口的 Base URL 是否为 <code>https://api.kkrich.ltd/v1</code>。</li><li>刷新模型列表，选择或手动填写 KKRICH 控制台可用模型名称。</li><li>打开 NewAPI 或新增接口旁边的开关，再保存配置。</li></ol><p><img src="/images/reference/apps-luna-translator-01.png" alt="从令牌管理页跳转到 Luna Translator"></p><p>进入 Luna Translator 后，打开 <code>设置</code>、<code>翻译设置</code>、<code>大模型</code>，可以看到新增的大模型接口配置。点击编辑，检查 API 地址是否为 <code>https://api.kkrich.ltd/v1</code>，API Key 是否已经写入。</p><p><img src="/images/reference/apps-luna-translator-02.png" alt="检查 Luna Translator 自动导入的 API 配置"></p><p>点击 <code>model</code> 下拉框旁边的刷新按钮获取模型列表，选择控制台可用的翻译模型；如果刷新失败，也可以手动输入模型名称。保存前再次确认模型名称没有多余空格。</p><p><img Token，便于统计翻译消耗。</p><p><img src="/images/reference/apps-luna-translator-05.png" alt="从令牌管理页复制 Luna Translator API Key"></p><p>在 Luna Translator 中进入 大模型设置中添加接口"></p><p>选择或复制大模型通用接口模板，新建一个接口配置。接口名称可以使用 <code>KKRICH</code> 或 <code>NewAPI</code>，只要能在列表中清楚区分即可。</p><p><img src="/images/reference/apps-luna-translator-07.png" alt="复制大模型通用接口模板"></p><p>在新增接口中填写 KKRICH 的接口地址和 API Key。API 地址固定填写 <code>https://api.kkrich.ltd/v1</code>，API Key 填写从令牌管理页复制的 Token。</p><p><img src="/images/reference/apps-luna-translator-08.png" Translator 手动接口配置"></p><p>点击模型刷新按钮获取模型列表，选择或输入用于翻译的模型名称。手动输入时以 KKRICH 控制台可用名称为准。</p><p><img src="/images/reference/apps-luna-translator-10.png" alt="为手动配置选择 KKRICH 翻译模型"></p><p>最后打开 NewAPI
