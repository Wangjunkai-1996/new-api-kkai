<div><h1 id="控制台" tabindex="-1">控制台 <a class="header-anchor" href="#控制台" aria-label="Permalink to &quot;控制台&quot;">​</a></h1><p><a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a> 是管理 KKRICH 账号、API Token、用量、充值和个人资料的中心入口。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>需要创建或管理 API Token。</li><li>需要查看余额、用量、日志和账务状态。</li><li>需要从网页直接进入聊天、Playground 或个人设置。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已通过 <a target="_self" href="https://api.kkrich.ltd/sign-in">登录页</a> 登录。</li><li>当前账号可正常访问 <code>https://api.kkrich.ltd/dashboard/overview</code>。</li></ul><h2 id="操作步骤" tabindex="-1">操作步骤 <a class="header-anchor" href="#操作步骤" aria-label="Permalink to &quot;操作步骤&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>先查看首页概览，确认余额、账号状态和近期使用情况。</li><li>进入 <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 创建或查看 API Token。</li><li>使用 <a target="_self" href="https://api.kkrich.ltd/playground/">聊天</a> 或 <a target="_self" href="https://api.kkrich.ltd/playground/">Playground</a> 做网页验证。</li><li>在 <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">日志</a> 中追踪请求结果。</li><li>需要充值时进入 <a target="_self" href="https://api.kkrich.ltd/wallet/">充值页</a>。</li></ol><p>控制台首页会集中展示余额、使用趋势和关键统计。先从这里判断账号是否可用，再进入令牌、日志、钱包和个人设置页面处理具体问题。</p><p><img src="/images/reference/guide/dashboard.png" alt="控制台首页数据看板"></p><p>如果某个页面打开异常，可以从侧边栏重新进入对应入口，确认不是路由或登录状态问题。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>控制台能显示账号信息和主要功能入口。</li><li>点击导航后能进入对应页面，且页面没有反复要求登录。</li><li>控制台中的余额、日志和令牌页面信息能正常加载。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>空白页或加载很久：刷新页面，检查网络代理和浏览器扩展。</li><li>功能入口不可见：确认账号是否完成登录，或是否使用了错误账号。</li><li>页面显示无权限：联系管理员确认账号角色和权限。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>阅读 <a href="./dashboard">仪表盘</a> 了解首页指标。</li><li>阅读 <a href="./api-token">API Token</a> 创建调用凭证。</li><li>阅读 <a href="./usage-log">使用日志</a> 学会定位 API 调用问题。</li></ul></div>
