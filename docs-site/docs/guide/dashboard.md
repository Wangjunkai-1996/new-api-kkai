<div><h1 id="仪表盘" tabindex="-1">仪表盘 <a class="header-anchor" href="#仪表盘" aria-label="Permalink to &quot;仪表盘&quot;">​</a></h1><p>仪表盘用于快速确认账号是否可用、余额是否充足，以及近期 API 调用是否正常。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>每天开始使用前检查账户状态。</li><li>排查工具突然无法调用时，先确认余额和近期错误。</li><li>团队管理员需要快速了解整体消耗趋势。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已登录 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>账号已经拥有至少一个可用 Token 或准备创建 Token。</li></ul><h2 id="操作步骤" tabindex="-1">操作步骤 <a class="header-anchor" href="#操作步骤" aria-label="Permalink to &quot;操作步骤&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>查看余额或额度信息，确认不会因余额不足导致请求失败。</li><li>查看近期用量、请求量或费用趋势。</li><li>如果仪表盘提供快捷入口，进入 Token、日志、充值或 Playground。</li><li>发现异常消耗时，立刻进入日志按时间和 Token 排查。</li></ol><p>数据看板会展示余额、请求量、消费趋势和常用统计，适合在开始使用前先确认账户状态和近期用量。</p><p><img src="/images/reference/guide/dashboard.png" alt="数据看板余额与近期用量"></p><p>进入数据看板后重点核对余额、请求趋势和异常消耗；这些指标以线上控制台实时展示为准。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>能看到账号余额或额度信息。</li><li>能看到最近请求、消耗或错误趋势。</li><li>从仪表盘进入其他控制台页面时不会丢失登录状态。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>余额显示异常：刷新页面后再确认，必要时查看充值记录。</li><li>近期用量与预期不符：按 Token、模型和时间范围查看日志。</li><li>无法打开快捷入口：从控制台主导航直接进入对应页面。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>到 <a href="./wallet">钱包充值</a> 补充额度。</li><li>到 <a href="./usage-log">使用日志</a> 查看明细。</li><li>到 <a href="./api-token">API Token</a> 为不同项目拆分令牌。</li></ul></div>
