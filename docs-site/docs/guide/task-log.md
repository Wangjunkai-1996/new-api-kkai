<div><h1 id="任务日志" tabindex="-1">任务日志 <a class="header-anchor" href="#任务日志" aria-label="Permalink to &quot;任务日志&quot;">​</a></h1><p>任务日志用于追踪异步任务、长耗时生成任务或平台后台任务。若当前控制台尚未提供独立任务日志入口，请先从 <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">日志</a> 中按任务相关筛选项查看。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>提交任务后没有立即拿到最终结果。</li><li>需要确认任务是排队中、执行中、成功还是失败。</li><li>需要排查长任务超时、取消或重复提交。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已登录 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>已提交会产生任务记录的请求。</li><li>验证提示：任务日志独立入口及字段名称需按线上控制台最终界面补充。</li></ul><h2 id="操作步骤" tabindex="-1">操作步骤 <a class="header-anchor" href="#操作步骤" aria-label="Permalink to &quot;操作步骤&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">日志</a>。</li><li>选择与任务相关的筛选项，或按提交时间搜索。</li><li>查看任务状态、模型、输入摘要、耗时和失败原因。</li><li>如果任务失败，先记录错误信息，再决定重试、缩短输入或更换模型。</li><li>对重复失败的任务，保留任务 ID 或日志 ID 供支持排查。</li></ol><p>任务日志会列出异步任务的状态、模型、提交时间和结果信息，适合排查绘图、音视频或其它长耗时任务。</p><p><img src="/images/reference/guide/task-log.png" alt="任务日志状态列表"></p><p>进入后重点核对状态字段和失败原因；如果当前线上页面还未开放独立入口，先从使用日志按时间筛选。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>能找到提交任务对应的记录。</li><li>任务状态能从排队或执行中更新为成功、失败或取消。</li><li>成功任务能关联到最终结果或消耗明细。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>任务一直排队：可能是模型繁忙，稍后重试或换用其他模型。</li><li>任务失败但没有明显原因：查看详情页错误字段，必要时联系支持。</li><li>重复提交导致费用增加：客户端应对超时和重试设置幂等策略。</li></ul><h2 id="下一步"
