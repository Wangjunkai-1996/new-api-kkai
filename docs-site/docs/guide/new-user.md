编程工具里，并在使用日志看到第一条成功请求。</p><p>如果你第一次来，先不要研究所有概念，按下面 6 步走完即可。</p><h2 id="最快路线" tabindex="-1">最快路线 <a class="header-anchor" href="#最快路线" aria-label="Permalink to &quot;最快路线&quot;">​</a></h2><table <code>sk-</code> 开头的密钥</td></tr><tr><td>3</td><td>从 Token 行打开 CC Switch 配置</td><td>浏览器尝试唤起 CC Switch</td></tr><tr><td>4</td><td>选择 Codex 和模型</td><td>CC Switch 自动生成 <code>My id="step-2-创建-api-token" tabindex="-1">Step 2：创建 API Token <a class="header-anchor" href="#step-2-创建-api-token" aria-label="Permalink to &quot;Step 2：创建 API Token&quot;">​</a></h2><p>点击添加令牌，填写一个容易识别的名称，例如 <code>codex</code>、<code>cursor</code> 或 <code>cherry-studio</code>。</p><p><img src="/images/feishu/feishu-04.png" alt="创建一个给 AI 编程工具使用的 API Token"></p><p>新手先用默认额度和分组即可；后续再根据项目设置限额。</p><h2 id="step-3-复制-token" tabindex="-1">Step 3：复制 Token <a class="header-anchor" href="#step-3-复制-token" aria-label="Permalink to &quot;Step 3：复制 Switch</code>。</p><p><img src="/images/feishu/feishu-01.png" alt="从 Token 行选择 CC Switch 配置入口"></p><p>选择 Codex，保持名称可识别，再选择一个当前可用的 GPT 模型。</p><p><img src="/images/feishu/feishu-02.png" alt="选择 Codex 和模型后打开 CC Switch"></p><p>正常情况下，系统会唤起 CC Switch，并自动把 Provider 配好。默认名称通常是 <code>My Codex</code>；如果你在弹窗里改过名称，就显示你改过的名称。</p><div class="tip custom-block"><p class="custom-block-title">还没安装 CC 或你刚才设置的名称。</li><li>这个 Provider 右侧显示“使用中”。</li></ol><p><img src="/images/feishu/feishu-08.png" alt="CC Switch 的 Codex 页签中，Provider 已显示使用中"></p><p>看到“使用中”就说明一键配置已经完成，不需要再点右上角加号，也不需要重新填写 API Key、Base URL 或模型。</p><p>确认后，重启 Codex 或重新打开终端，再做测试。</p><h2 id="step-6-测试是否成功" tabindex="-1">Step 6：测试是否成功 <a class="header-anchor" href="#step-6-测试是否成功" aria-label="Permalink to &quot;Step 6：测试是否成功&quot;">​</a></h2><p>打开 Codex 或你的 AI 编程工具，发送一句：</p><div class="language-text vp-adaptive-theme line-numbers-mode"><button title="Copy Code" class="copy"></button><span 请求地址</td><td><code>https://api.kkrich.ltd/v1</code></td></tr><tr><td>模型名称</td><td>控制台可用 GPT 模型名称</td></tr></tbody></table><p><img src="/images/feishu/feishu-07.png" alt="手动新增 Provider 时填写 API Key、Base URL 和模型名称"></p><p>保存后启用 Provider，确认它显示“使用中”，再重启 Codex 测试。</p><p>如果仍然不生效，阅读 <a href="./../apps/cc-switch-manual">手动切换配置</a>。</p><h2 id="其它工具怎么填" tabindex="-1">其它工具怎么填 <a class="header-anchor"
