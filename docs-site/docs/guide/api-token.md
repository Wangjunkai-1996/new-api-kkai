<div><h1 id="api-token" tabindex="-1">API Token <a class="header-anchor" href="#api-token" aria-label="Permalink to &quot;API Token&quot;">​</a></h1><p>API Token 是调用 KKRICH OpenAI 兼容接口的凭证。请把 Token 当作密码管理，不要提交到代码仓库、截图或公开聊天中。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>后端服务、脚本、AI 客户端需要调用 <code>https://api.kkrich.ltd/v1</code>。</li><li>需要为不同项目、成员或环境分配独立调用凭证。</li><li>需要停用泄露、过期或不再使用的 Token。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已登录 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>当前账号有创建 Token 的权限。</li></ul><h2 id="操作步骤" tabindex="-1">操作步骤 <a class="header-anchor" href="#操作步骤" aria-label="Permalink to &quot;操作步骤&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a>。</li><li>创建新 Token，并使用能识别用途的名称，例如 <code>prod-api</code>、<code>local-codex</code>、<code>postman-test</code>。</li><li>如页面支持额度、过期时间或模型范围限制，按项目需要设置最小可用权限。</li><li>创建后立即复制 Token，并保存到密码管理器或部署平台密钥管理中。</li><li>在客户端中使用 <code>Authorization: Bearer &lt;Token&gt;</code>。</li><li>不再使用时删除或禁用对应 Token。</li></ol><p>令牌管理页的「添加令牌」是创建 API Token 的入口，同时列表里可以看到已有令牌的状态、复制按钮和操作区。</p><p><img src="/images/reference/guide/api-token.png" alt="令牌管理入口与列表"></p><p>创建时先填写名称，再设置过期时间、额度和访问限制；这些字段决定 Token 后续能被哪些项目安全使用。</p><p><img src="/images/reference/guide/create-api-token.png" alt="创建令牌表单字段"></p><p>创建成功后回到列表，确认状态为已启用，并使用复制按钮把 Token 放入环境变量或客户端配置中。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>使用该 Token 调用 API 返回成功响应。</li><li>日志中能识别请求来自对应 Token 或项目。</li><li>删除 Token 后，使用旧 Token 的请求会被拒绝。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>创建后找不到完整 Token：多数平台只在创建时展示一次，需要重新创建。</li><li>多个环境共用一个 Token：难以定位异常消耗，建议按项目拆分。</li><li>Token 泄露：立即删除旧 Token，创建新 Token，并检查日志中的异常请求。</li><li>复制时多了空格或换行：重新复制并确认环境变量值。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>参考 <a href="./quickstart">API 快速开始</a> 完成 API 调用。</li><li>参考 <a href="./usage-log">使用日志</a> 检查 Token 调用明细。</li><li>前往 <a href="./../apps/">AI 应用</a> 配置常用客户端。</li></ul></div>
