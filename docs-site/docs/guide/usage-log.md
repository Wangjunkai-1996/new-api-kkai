<div><h1 id="使用日志" tabindex="-1">使用日志 <a class="header-anchor" href="#使用日志" aria-label="Permalink to &quot;使用日志&quot;">​</a></h1><p><a target="_self" href="https://api.kkrich.ltd/usage-logs/common">使用日志</a> 是排查 API 调用问题的首选页面。它能帮助你确认请求是否到达平台、使用了哪个模型，以及失败原因是什么。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>API、聊天或第三方工具返回错误。</li><li>需要核对某个项目、Token 或模型的消耗。</li><li>需要追踪异常调用和突增费用。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已登录 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>。</li><li>已发生至少一次聊天、Playground 或 API 调用。</li></ul><h2 id="操作步骤" tabindex="-1">操作步骤 <a class="header-anchor" href="#操作步骤" aria-label="Permalink to &quot;操作步骤&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/usage-logs/common">日志</a>。</li><li>按时间范围定位问题请求。</li><li>如页面支持筛选，按模型、Token、状态或应用来源过滤。</li><li>查看状态码、错误信息、请求耗时、消耗和返回结果摘要。</li><li>复制必要的错误信息用于工单或团队内部排查，避免复制完整 Token。</li></ol><p>使用日志会展示请求时间、模型、状态、消耗和错误信息，适合在 API、聊天或第三方客户端调用后立刻核对记录。</p><p><img src="/images/reference/guide/usage-log.png" alt="使用日志列表与筛选区域"></p><p>验证时重点看请求时间、模型、状态和消耗；如果没有记录，优先检查 Base URL 是否指向 <code>https://api.kkrich.ltd/v1</code>。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>能看到与客户端请求时间一致的日志。</li><li>成功请求显示模型和消耗。</li><li>失败请求能提供可行动的错误原因，例如认证失败、余额不足或模型不可用。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>找不到日志：确认请求 Base URL 是否为 <code>https://api.kkrich.ltd/v1</code>。</li><li>日志显示成功但客户端失败：检查客户端解析、超时设置或流式处理。</li><li>日志显示 <code>401</code>：重新检查 Token。</li><li>日志显示余额不足：前往 <a href="./wallet">钱包充值</a>。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>阅读 <a href="./task-log">任务日志</a> 和 <a href="./drawing-log">绘图日志</a> 了解专项日志入口。</li><li>根据错误类型回到 <a href="./api-token">API Token</a>、<a href="./pricing">定价</a> 或 <a href="./playground">Playground</a> 继续排查。</li></ul></div>
