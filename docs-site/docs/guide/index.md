<div><h1 id="使用指南" tabindex="-1">使用指南 <a class="header-anchor" href="#使用指南" aria-label="Permalink to &quot;使用指南&quot;">​</a></h1><p>本指南面向第一次使用 KKRICH / KKAI New API 的用户。新客建议先走 <a href="./new-user">新手上手</a>，把 Codex 或 AI 编程工具跑起来；开发者再看 <a href="./quickstart">API 快速开始</a>。</p><h2 id="适用场景" tabindex="-1">适用场景 <a class="header-anchor" href="#适用场景" aria-label="Permalink to &quot;适用场景&quot;">​</a></h2><ul><li>需要快速接入 OpenAI 兼容接口的开发者。</li><li>需要在网页控制台体验对话、Playground、日志和余额管理的用户。</li><li>需要把 KKRICH 配置到 Codex、Cursor、Cherry Studio、Postman 等工具中的团队。</li></ul><h2 id="前置条件" tabindex="-1">前置条件 <a class="header-anchor" href="#前置条件" aria-label="Permalink to &quot;前置条件&quot;">​</a></h2><ul><li>已能访问 <a target="_self" href="https://api.kkrich.ltd/">KKRICH 官网</a>。</li><li>已准备可接收登录验证的账号。</li><li>如需调用 API，需在控制台创建 API Token，并确认账户有可用额度。</li></ul><h2 id="新手推荐路线" tabindex="-1">新手推荐路线 <a class="header-anchor" href="#新手推荐路线" aria-label="Permalink to &quot;新手推荐路线&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/sign-in">登录页</a> 完成登录。</li><li>进入 <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a>，创建并复制 API Token。</li><li>从 Token 行选择 CC Switch，一键配置 Codex。</li><li>如果 Windows 没有弹出 CC Switch，按 <a href="./../apps/cc-switch-manual">手动切换配置</a> 填写。</li><li>打开 Codex，发送“请回复：配置成功”。</li><li>在 <a href="./usage-log">使用日志</a> 中确认请求、模型和消耗。</li></ol><p>图文版请直接看 <a href="./new-user">新手上手</a>。</p><h2 id="控制台和-api-路线" tabindex="-1">控制台和 API 路线 <a class="header-anchor" href="#控制台和-api-路线" aria-label="Permalink to &quot;控制台和 API 路线&quot;">​</a></h2><ol><li>打开 <a target="_self" href="https://api.kkrich.ltd/sign-in">登录页</a> 完成登录。</li><li>进入 <a target="_self" href="https://api.kkrich.ltd/dashboard/overview">控制台</a>，查看账户概览和导航入口。</li><li>在 <a target="_self" href="https://api.kkrich.ltd/keys/">令牌管理</a> 创建 API Token。</li><li>参考 <a href="./quickstart">API 快速开始</a> 发起一次最小 API 请求。</li><li>如需网页调试，使用 <a href="./chat">聊天</a> 或 <a href="./playground">Playground</a>。</li><li>在 <a href="./usage-log">使用日志</a> 中确认请求、费用和错误信息。</li><li>将相同的 Base URL 与 Token 配置到 <a href="./../apps/">AI 应用</a>。</li></ol><p>下图展示控制台首页的数据看板。第一次进入时，先确认余额、用量趋势和左侧导航，再进入令牌、日志、钱包等页面继续操作。</p><p><img src="/images/reference/guide/dashboard.png" alt="控制台首页与数据看板"></p><p>确认入口位置后，可以按上面的顺序先创建 Token，再到日志里验证调用记录。</p><h2 id="成功验证" tabindex="-1">成功验证 <a class="header-anchor" href="#成功验证" aria-label="Permalink to &quot;成功验证&quot;">​</a></h2><ul><li>能登录控制台并看到余额、用量或账号信息。</li><li>能创建并复制 API Token。</li><li>使用 <code>https://api.kkrich.ltd/v1</code> 发起请求后，日志中出现对应记录。</li><li>第三方工具中能返回模型响应，而不是认证或网络错误。</li></ul><h2 id="常见失败" tabindex="-1">常见失败 <a class="header-anchor" href="#常见失败" aria-label="Permalink to &quot;常见失败&quot;">​</a></h2><ul><li>登录后反复回到登录页：检查浏览器 Cookie、网络代理和账号状态。</li><li>API 报 <code>401</code>：Token 缺失、复制不完整、被删除或填错了 Authorization 格式。</li><li>API 报 <code>404</code>：Base URL 多写了一层 <code>/v1</code>，或工具要求填写根地址而不是完整 API 地址。</li><li>API 报额度不足：前往 <a target="_self" href="https://api.kkrich.ltd/wallet/">充值页</a> 或检查限额配置。</li></ul><h2 id="下一步" tabindex="-1">下一步 <a class="header-anchor" href="#下一步" aria-label="Permalink to &quot;下一步&quot;">​</a></h2><ul><li>从 <a href="./new-user">新手上手</a> 完成第一次 Codex / CC Switch 配置。</li><li>从 <a
