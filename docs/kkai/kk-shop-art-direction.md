# KK 商城视觉决策与美术指导

版本：V1；日期：2026-10-27；状态：视觉方向已选定，素材及关键页面截图已完成美术评审；设计稿待用户审核。

本次采用“奶油白＋钴蓝的纸艺数字陈列室”。主品牌保持 **KK 商城 / KKAI**，现有 `new-api / QuantumNous` 归属信息保留。

本文件规定原创插画、视觉层次和页面美术处理，不改变 [PRD](./kk-shop-prd.md) 与 [业务规则](./kk-shop-business-rules.md)。组件、状态和响应式实现同时遵守 [UI 规格](./kk-shop-ui-spec.md)。图片生成结果与页面截图须经实际审核，不能仅凭本文件宣布视觉完成。

## 1. 三个方向与最终选择

| 方向 | 颜色与排版 | 图形语言 | 优点 | 主要风险 |
| --- | --- | --- | --- | --- |
| **A：纸艺数字陈列室，采用** | 奶油白、墨色、钴蓝，局部杏橙；大标题与清晰商品文字 | 有折面、叠层、纸边和柔软投影的立体纸艺 | 商品有独立记忆点；温暖但有秩序，适合主站内的数字商品商店 | 太圆润会玩具化；堆太多物件会像装饰素材合集 |
| B：朱红编辑部 | 象牙白、近黑、朱红，少量明黄；强对比标题、少圆角 | 丝网印刷、拼贴、颗粒与平面剪纸 | 辨识度高，适合独立设计内容 | 红色容易混同促销、错误与风险；与现有主站蓝色语言跨度大 |
| C：深绿数字档案馆 | 深墨绿、米白、鼠尾草与少量黄铜；编号式布局 | 拉丝铝、磨砂陶瓷、定向光与陈列空间 | 稳重，适合高客单价工具 | 容易像金融或硬件商店；暗色材质不利于快速阅读交易信息 |

选择 A 的依据：目前商品图只是相近颜色的单字母卡片，缺少可识别的内容。纸艺能够为六款数字商品建立不同主体，同时共享材质、光线和色彩，让页面形成完整的美术体系。钴蓝承接 KKAI 的蓝色交互语义；奶油背景让前台购物体验与技术控制台有所区分。

本方向不依赖第三方品牌、虚假销量或促销话术。可信感由明确商品规则、可读金额、准确状态和完整售后入口共同建立；插画负责表达用途与气质。

## 2. 色彩、排版与留白

### 色彩

| 用途 | 推荐值 | 使用原则 |
| --- | --- | --- |
| 商城画布 | `#F6F3EC` | 暖而接近白色；用于首页与详情外部背景 |
| 内容面板 | `#FFFFFF` | 商品信息、结账、订单、表单和后台主要阅读区 |
| 主文本 | `#17212C` | 标题、金额及关键事实 |
| 次文本 | `#5F6772` | 说明、时间和辅助信息；不得用过浅灰色承载规则 |
| 主色 | `#2456D6` | 购买、确认和当前选中项；通常配白字 |
| 主色浅底 | `#EAF0FF` | 分类选中、普通提示或轻量强调 |
| 插画暖色 | `#E3A171` | 只作局部图形点缀，不能替代错误或待处理状态色 |
| 边框 | `#DDD9D1` | 暖底上的区域分隔；白面板内可使用主站边框 token |

钴蓝是视觉锚点，不铺满所有区域。商品图可以使用鼠尾草、蓝绿、珊瑚与浅蓝，但文字、按钮、状态继续使用一致的语义颜色。成功、待处理、风险必须有图标和文字，不能通过商品图颜色表达业务状态。

正式前端把这些值映射到现有主题与 semantic tokens，不另建不跟随主站切换的主题系统。浅色与深色均须检查文字、边框、按钮和焦点对比度；色值建议不等于已经通过可访问性验证。

### 排版与密度

| 元素 | 桌面建议 | 手机建议 | 约束 |
| --- | --- | --- | --- |
| 首页主标题 | 48–52px / 1.15 | 32–36px / 1.2 | 不超过两行，正常中文字距；不压缩到难读 |
| 页面标题 | 30–36px / 1.25 | 26–30px / 1.3 | 与正文拉开层级，不靠多层描边装饰 |
| 商品名称 | 18px / 1.45 | 15–17px / 1.45 | 最多两行，规格作为独立文字 |
| 价格 | 26px / 1.2 | 22–24px / 1.2 | 带币种；数字等宽，价格与购买动作相邻 |
| 正文与表单 | 15px / 1.65 | 14–15px / 1.65 | 交付、售后和金额说明不能为美观缩成小字 |
| 标签与时间 | 12–13px / 1.5 | 12–13px / 1.5 | 仅用于次要信息，不能取代正文规则 |

字体使用现有系统无衬线中文栈，保持与 KKAI 一致；依靠字号、字重和行距建立层级，不为装饰引入网络字体。标题 600–650、正文 400、商品与价格 600 为推荐起点。

内容最大宽度沿用约 1240px；桌面页边 32px、手机 18px。主要区域间隔 40–56px，卡片间隔 20–24px，卡片文字内边距 20px 左右；手机压缩至 16px。圆角维持主站的 16px 基础，首页插画区可到 24px；不把所有控件做成胶囊。

## 3. 页面级艺术指导

| 页面类别 | 节奏与构图 | 插画使用 | 必须保留的信息 |
| --- | --- | --- | --- |
| 商城首页 | 低高度左文右画横幅，随后分类、搜索和三列商品；首屏露出商品 | Hero 是唯一大场景，六商品图提供连续而不同的视觉节奏 | 分类、真实商品类型、规格、价格/币种、交付方式和库存状态 |
| 商品详情 | 主图与说明约占 60%，购买摘要约占 40%；按交付、适用与售后分段 | 放大同一商品图，不生成风格冲突的详情主图 | 使用条件、交付内容、期限、查看期限、质保及退款规则 |
| 确认与付款 | 白色内容面板，商品摘要、资料、规则、金额和主动作自上而下 | 只保留小商品缩略图；不出现大 Hero 或会分散注意的动效 | 数量 1、真实应付金额、币种、渠道、协议与付款核实状态 |
| 我的订单与交付 | 列表以文字和进度为主；详情区分状态、交付和历史 | 小图辅助识别商品；凭据区域使用纯净背景 | 付款、交付、售后独立事实，以及当前真正可执行的动作 |
| 售后、退款与异常 | 清楚说明问题与下一步；颜色克制 | 不用可爱插画掩盖已收款、退款失败或风险暂停 | 原规则、处理记录、证据摘要、补充入口与明确状态 |
| 管理后台 | 高密度但有分组；待办优先，表格与表单保持稳定对齐 | 商品列表只用小缩略图；无装饰性 Hero；可在纯空载时使用小图 | 责任人、期限、事实、差异、敏感操作及审计入口 |

首页横幅建议高 320–360px，右侧插画占约 55%，左侧保留标题、简短说明和一个主要动作。分类与商品不能被全屏插画挤到下一屏。手机插画保留约 120–150px 的局部展示或独立短图带，不能把新增美术素材全部隐藏。

商品封面采用完整、清楚的主体。商品名称、价格、演示标记和交付状态全部在 HTML 文本层展示；不得把按钮、状态或可点击元素画进图片。

详情页在手机上改为单列，购买栏只放当前金额和购买动作。规则始终能正常阅读，不能为了腾出插画空间折叠掉关键交易信息。

## 4. 九张专属图的统一规则

本轮资产清单固定为 **Hero、六款商品图、服务流程图、空载图，共九张**。下表采用逻辑资产 ID；实际文件名由生成结果确定，接入时建立一一对应关系，不依赖外部图片服务。

所有图使用厚哑光彩纸、精确折面、层叠纸边和轻微纸纤维；上左侧大柔光，柔软接触阴影；约 35° 俯视的三分之四机位。共同背景为奶油白，钴蓝是主要连接色。不要同时混用玻璃、镀铬、霓虹、拟人机器人和塑料软糖。

图中是数字功能的美术隐喻，不能出现运输纸箱、快递车、货架包装、物流标签或其他暗示实物配送的符号。纸艺质感不能使商品描述看起来在出售插画中的实体摆件。

### 输出与接入

- 商品图与空载图采用方形母图，建议至少 1024px；Hero 与服务流程图采用横向母图，尺寸按生成工具支持能力选择。先保留高质量原图，再输出适合页面的本地压缩版本。
- 商品卡优先使用约 4:3 的浅色图框，母图通过留白和适当缩放完整放入；不把主体硬裁断。详情复用同图，使用更大的 `contain` 式展示。
- 每张商品主体的视觉重量、落地位置和阴影方向一致；辅助色可以不同，但不能六张各像一套独立素材。
- 图片不得包含文字、字母 Logo、二维码、价格、按钮、评分、认证徽章或第三方品牌。文字由页面实现，方便国际化、移动布局和读屏。
- 首屏主图优先加载；非首屏商品图可延后加载。为图片声明尺寸或比例，避免加载时推动购买区域跳动。
- 深色主题保留插画的原奶油纸张背景，以受控的图框呈现；不要反相、强行换色或叠加重滤镜。保证图框与周围深色页面过渡清楚，减少大块高亮面积。
- 装饰性 Hero 和指南图可使用空替代文本，旁边提供完整文字；商品图若与名称处于同一链接内，避免读屏重复播报。任何购买规则不得仅存在于图片中。

## 5. 图片生成的艺术约束

共享生成描述应保持材质、机位、光源和背景一致，只替换主体与辅助色。以下是美术基线，实际生成仍使用本次选定的图像模型和工具能力。

> Art-directed miniature paper sculpture for a contemporary digital goods store. Warm ivory seamless studio background, cobalt blue dominant forms, one restrained secondary color. Thick matte colored paper with precise folds, layered edges, subtle paper fibers, soft realistic contact shadows. Consistent 35-degree elevated three-quarter camera angle, soft key light from upper left. One clearly readable symbolic subject, generous clean margins, beautiful at small thumbnail scale. A digital-service metaphor. No text, no letters, no logo, no interface, no packaging, no shipping symbols, no real brand, no watermark, no chrome, no glass blobs, no neon, no security badge.

Hero 加入“横向、右侧视觉重心、单一场景”；六商品图加入对应主体与辅助色；指南图加入“三个有序装置、图外另配真实步骤文字”；空载图加入“一个轻量主体、无错误或失败暗示”。

生成后需要逐张审查。固定提示词不能保证一致性，不合格图应修正或重做；禁止用强滤镜掩盖材质与光线差异，也不把六张商品塞进一张拼图后依赖裁切修补。

## 6. 产品事实与美术边界

- KK 商城 / KKAI 的名称、Logo 和既有归属由页面真实内容展示；图片不生成新品牌标识，也不模拟已经存在的第三方授权。
- 所有演示商品、价格、服务时限、质保、库存及付款信息继续明确标注演示；图中的形状或符号不代表安全担保、官方认证或到账承诺。
- 不以图片伪造商城界面、支付二维码、账户凭据、订单证据、售后对话或运行结果。生图素材必须作为插画使用，不作为实际操作界面的截图。
- 交付方式以真实文字区分自动与人工；同样精美的商品图不能暗示人工服务即时完成。
- 付款未知、风险暂停、退款失败与资金争议使用准确状态文案和操作入口，不用装饰图冲淡问题，也不把红色全部替换成品牌蓝。
- 前台可增强视觉表现，结账和后台仍须保留现有信息层级、业务动作与可访问性，不因重做美术删减需求。

## 7. 美术与页面审核标准

| 审核 ID | 检查点 | 通过标准 |
| --- | --- | --- |
| ART-QA-01 | 九图齐备与用途 | 九个逻辑资产均有对应结果；各图的使用位置与本表一致，未混用真实商品素材 |
| ART-QA-02 | 系列一致性 | 纸材、机位、光源、背景温度与主体尺度统一；六款轮廓清楚且有区别 |
| ART-QA-03 | 图像质量 | 无多余字形、伪 Logo、杂乱薄片、断裂结构、脏边或明显生成瑕疵；缩略图仍可辨识 |
| ART-QA-04 | 首页信息顺序 | 1440px 常见桌面视口内能看到分类与首排商品；手机保留美术特点，同时能迅速开始选购 |
| ART-QA-05 | 商品与交易可读性 | 名称、规格、价格/币种、交付、库存与规则清晰；无文字烘焙进图片；没有插画遮挡按钮 |
| ART-QA-06 | 语义与诚信 | 无虚假销量、评级、保障、秒发、第三方品牌背书或物流暗示；演示信息清晰可见 |
| ART-QA-07 | 响应式与主题 | 390px 与 320px 无整页横向溢出；主体不裁坏；深色主题不反相图片、不丢失状态对比 |
| ART-QA-08 | 操作可访问性 | 焦点、标签、按钮文字与状态清楚；插画不成为唯一说明；实际对比度与键盘路径完成检查 |
| ART-QA-09 | 业务回归 | 浏览、单件直接购买、付款核实、领取、人工交付、售后与后台关键动作仍符合 PRD；美术更新不改变交易事实 |

### 系列、裁切与语义结论

- **系列一致性通过：**背景温度、纸张纹理、钴蓝饱和度及主要光线方向接近。商品 3 更有装置感、商品 4 更有书本形态，属于可接受的题材差异；不需要以滤镜强行抹平。
- **缩略辨识通过：**已检查六款 320px 优化图，主要轮廓和内容主题均保留。移动双列约 160px 的实际展示仍需页面截图复核，不能用原图审查替代。
- **原图裁切空间可用：**六张方图的主体完整，但书本、色样和文件面板的边缘较近。页面优先完整展示，若使用不同图框比例，应由留白补齐，不能统一强裁。
- **图像事实边界通过：**未见文字、第三方 Logo、价格、二维码、假支付界面、物流标签、包裹或认证徽章。书本和模块是纸艺隐喻，商品卡及详情仍须清楚写出账号、卡密或人工服务，不把插画称为商品实拍。
- **服务图不承担交易判断：**指南里的票券、门与日光不决定付款或交付状态，流程说明和当前状态来自页面文字。
- **素材保持原色：**移动 Hero 与商品缩略图未见明显压缩损伤；深色页面保留纸张背景，不采用反相或强滤镜。

### 概念插画与真实商品替换限制

九张纸艺图是原创概念插画，表达创作、记录、阅读与配置等用途，不展示真实应用界面、账户权益、实物或服务执行结果。当前页面的演示标记、商品类型和交付说明必须继续保留。

真实商品上线前，运营需要核对图意、名称、适用范围与实际交付是否一致。若概念图仍适用，可以作为明确标注的插画继续使用；若需要展示真实服务功能，应使用获准的真实截图或重新制作匹配素材，不能把现有纸艺图改称实拍、把生图界面冒充运行效果，或仅替换品牌名称就暗示第三方授权。

后续替换素材须维持主体完整、图框比例、足够分辨率及可访问文字，不能将价格、期限、交付状态和按钮烘焙进图。更换品牌或商品类目后，需要再次检查语义和授权依据，而不是只比较画面是否好看。
