# 视频工作室视觉与交互复核

日期：2026-10-28。基线：[PRD v1.1](./prd.md)、[视觉与交互规范](./ui-spec.md)。复核角色：视觉艺术指导、交互设计、无障碍与体验质量。

这是独立代理视角的设计复核记录，不是实际用户测试、真人专家签字或用户已批准。原型使用演示数据和静态封面，不连接真实生成与计费服务。

## 1. 本次证据与结论

已实际查看三张完整页面截图，而非仅阅读代码：

- [桌面浅色](./screenshots/desktop-light.png)
- [桌面深色](./screenshots/desktop-dark.png)
- [移动浅色](./screenshots/mobile-light.png)

同时核对 `design.html`、`design.css`、`design.js` 的场景入口、核心交互与对应样式。其他视口、场景和浏览器操作由主执行者记录于 [设计 QA](./design-qa.md)，本文件不把未亲自观察的场景记为视觉实测。

上述三个画面已完成修订后再次目视复核，具备用户方向审查条件：浅色延续图片工作室的冷灰、白卡与靛蓝，深色使用相同层级；桌面将输入与成果并置，视频画面成为主要视觉焦点；手机按编辑、成果、近期、灵感顺序展示，费用和生成按钮完整可见。所看截图没有文字重叠、横向裁切或按钮覆盖正文。本轮提出的视觉收尾项已关闭，没有遗留的方向审查阻断项。

## 2. 文档层缺口复核

UX 首轮五项缺口均已写入 PRD v1.1：系统/组件状态 D09、断网时的旧快照说明、焦点与关键状态播报、活动媒体双向互斥、小屏/软键盘/200% 文字验收。文档层关闭；真实业务行为仍需在实施阶段验证。

## 3. 出稿过程中已收敛的具体问题

| 问题 | 修订结果与本次证据 |
| --- | --- |
| 费用、错误、状态等说明曾使用大量 9–10px 小字 | 主要说明已提升到 12px，手机输入为 16px；截图中的费用、模型说明、任务元信息可辨 |
| 媒体控件、模式按钮、展开按钮等存在小于 44px 的触控目标 | 原型增加统一最小点击区域规则；截图保留小图标外观，不依靠放大图标制造拥挤；全部实际命中尺寸以浏览器 QA 为准 |
| 980px 容器档的编辑栏曾收窄至 350px | 收敛为 PRD 允许的 380px，空间不足时整体单栏 |
| 浅色输入边界与白卡区分不足 | 必要输入边界使用独立 `control-line`，装饰卡片保留轻边框；两主题截图可辨 |
| 深色按钮与状态色需要一致前景 | 深色实心主按钮使用 `#18203a` 深字，状态色与语义变量对齐，未沿用白字造成低对比 |
| 必需素材尚未添加时，禁用生成但提示仍显示通用费用说明 | 原型区分缺素材、上传中断、检查中；费用区在素材未就绪时不展示可提交报价 |
| 任务页“查看作品”只切换页面，未把目标明确展示出来 | 原型改为进入作品库后打开目标详情；选择样式同时保留 |
| 删除当前作品后出现空选择 | 原型删除成功后选择仍有效的记录；不存在记录才进入空态 |

## 5. 未由本次视觉复核证明的内容

本次没有验证真实播放/下载、媒体签名续期、跨页单播放器管理、上传续传、真实报价/扣费、未决提交持久化、换账号隔离、跨标签行为，也没有通过截图验证读屏、手机软键盘、系统文字缩放或所有浏览器。

这些能力的规则已在 PRD 和规范中落地，原型只展示其用户界面和交互意图。当前评审结果不应表述为“无遗漏”“生产验收通过”或“用户已接受设计”。

## 6. 第二轮暗色、素材与动效审查

本轮依据用户对素材不足、组件质感与动效缺失的反馈重新审查。已实际查看第二轮的 [暗色桌面](./screenshots/dark-v2-desktop-review.png)、[390px 暗色手机](./screenshots/dark-v2-mobile-review.png)，并只读核对最终 `design.css` 的字号、控件、动效与减少动态效果规则。该复核不使用第一轮截图代替新稿证据。

第二轮主成果采用新生成的城市骑行电影画面；灵感入口和首访引导加入同轮生成的电影器材静物。暗色由中性墨色页面、稍亮工具表面与更深媒体舞台形成层级，主操作保留靛蓝。模型几何标记、带图标的模式切换、可辨识的画幅比例按钮构成一致的工具组件。桌面画面仍为主焦点，手机完整显示编辑、费用、成果和近期作品，所看截图无文字重叠或横向裁切。素材标记为示例封面，播放器控件标记为演示，不把静态画面作为真实生成或播放证据。

| 第二轮发现 | 修订与复核结果 |
| --- | --- |
| 新增桌面 CSS 覆盖手机输入 16px 规则，提示词和选择器变小 | 最终手机规则恢复 `textarea`、输入与选择器 16px；新手机截图输入清晰，计算样式由主执行者浏览器验证 |
| 费用说明、模型说明、时间、作品元信息降至 11px | 必要元信息回到 12px；新桌面与手机截图可辨，纯装饰标记不承担必要信息 |
| 减少动态效果只取消动画，按钮和卡片仍有悬停位移 | 最终规则取消按钮、卡片、上传槽、侧栏、模式图标与灵感图片的非必要位移/缩放；实际媒体偏好验证由主执行者记录 |
| 模型、模式与画幅仍接近普通表单外观，素材仅集中在主舞台 | 加入模型几何标记、模式线图标、比例图形按钮和静物灵感入口；最终截图体现组件分工，未增加业务能力 |

动效源码包括结果与提示入场、弹层显现、作品卡片反馈、模式按下、费用变化和生成阶段反馈；其作用是让操作与状态变化可见。独立截图复核不能证明动效节奏，实际触发结果及浏览器矩阵见 [设计 QA](./design-qa.md)。生成、归档与未知状态的文字规则未被动效替代。

截至本轮所看最终截图与所读样式，没有新增的方向审查阻断项；第二轮视觉仍待用户审查，不代表用户认可、全功能验收或生产质量结论。
