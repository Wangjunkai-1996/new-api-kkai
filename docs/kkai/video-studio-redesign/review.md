# 视频工作室产品文档交叉审查记录

审查日期：2026-10-28。审查基线：[PRD v1.1](./prd.md)。

本轮由产品完整性、前后端架构与计费安全、交互与可访问性三个独立角色审查 PRD v1.0，共提出 12 项发现：4 项 P1、8 项 P2。修订已纳入 v1.1，并按下表复核文档闭环。P1 表示进入设计前需要澄清的功能或安全边界；P2 表示需要补齐的交互、范围或验收细节。

**“文档已关闭”表示需求及验收约束已经补齐，不代表业务代码已实现、运行行为已验证、设计稿已通过验收，或用户已经批准。** 本记录不承诺绝对不存在遗漏。用户的视觉与交互确认仍待进行。

## 3. 前后端架构、计费与权限契约

| 编号 | 严重度 | 需求 ID | 发现及影响 | 修订位置与闭环依据 | 当前状态 |

| A-01 | P1 | VS-08 | 相同幂等键仅在有效窗口内提供防重；视频记录超过24小时可被回收，不能沿用图片专属延长规则或在过期后承诺原请求重放安全。 | 第5节第3项明确服务端首次预留起24小时及本地时间证据局限；超期或证据不可靠时只读核实，不自动清除提醒或重放 POST。第7节数据维度增加超过24小时场景。 | 文档已关闭；边界实现未验证 |
| A-02 | P1 | VS-07、VS-08、VS-19 | 若仅收到 unknown 错误后才保存记录，发送后刷新、关闭或响应丢失仍会失去身份；记录只存在组件 ref 不能承诺跨刷新恢复。 | 第5节第1、2、5项：POST 前持久化，失败阻止发送；断网、超时、无法解析和服务端 unknown 均待核实；不覆盖其他未决记录，跨账号及迟到回执隔离。第7节增加对应数据场景。 | 文档已关闭；持久化/时序验证待实施 |

- [service/video_generations.go](../../../service/video_generations.go)、[api.ts](../../../web/default/src/features/video-studio/api.ts)：字符串 task_id、数字 generation ID、有限列表筛选与公开状态投影。

## 4. 复核结论与交付边界

12项发现均已在 PRD v1.1 中获得可追踪的修订位置；当前没有本轮已发现但未处理的产品文档阻塞项，可以据此制作供用户审查的设计稿。

本期恢复方案限定为跨刷新保留未决提醒、使用已有任务号的只读查询或有限列表发现；恢复动作不产生生成请求。当前未提供按 task_id 精确查询的工作室接口，不能在设计稿中将此能力包装为已经可用。

本轮复核只阅读文档和源码，没有运行业务测试、全量测试、生产检查或付费模型请求。没有证明跨刷新持久化、幂等边界、账户切换、签名续期、真实媒体互斥及可访问性行为已经实现。实施阶段须按 PRD 第7节做定向验证；视觉稿还须核对 D01–D09 场景与用户反馈。
