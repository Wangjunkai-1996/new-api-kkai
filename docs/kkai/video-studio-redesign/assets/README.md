# Video Studio redesign demo assets

These images were generated with KKRICH `gpt-image-2` for design review only. They are not real generated-video thumbnails, and must not be used as a production fallback for missing user media.

| Asset | Actual size | Suggested design use |
| --- | --- | --- |
| `city-ride-cinematic.webp` | 1536 x 864, 16:9 | Clearly labeled sample result / gallery image |
| `cinema-tools-still-life.webp` | 1024 x 1024, 1:1 | Dark empty-state or inspiration artwork, shown as a complete composition |

The matching PNG files are source originals. Both images are opaque RGB; the still life has no transparent cutout. WebP is the lighter prototype delivery format. Keep the example label visible wherever a sample image could be mistaken for an actual user result.
