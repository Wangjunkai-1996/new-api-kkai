## 如何查看设计稿

直接用浏览器打开 `design.html`，其CSS、JS和仓库内封面采用相对路径。也可在仓库根目录运行：

```sh
python3 -m http.server 4874 --bind 127.0.0.1 --directory docs/kkai
```

打开 <http://127.0.0.1:4874/video-studio-redesign/design.html?theme=dark>。默认呈现暗色。设计稿使用示例任务、模型规格和金额；模拟提交、播放、下载及上传不会调用真实服务。静态封面明确标注为“示例封面”。刷新或更换审查场景会重置演示数据；页面导航保留本次演示草稿。

新增的[城市骑行画面和电影器材静物](assets/README.md)由 KKRICH `gpt-image-2` 生成。电影器材 WebP 已用于正式创作页面的装饰插画；城市骑行画面仍用于设计与本地验证示例。它们不是已生成的视频，也不作为缺失用户媒体的默认补图。

实际应用的截图位于 [screenshots/implementation](screenshots/implementation)，与本目录其他静态原型截图分开保存。检查入口、fixture 边界和浏览器证据见[实施与验收记录](implementation-qa.md#6-真实-react-视觉与媒体证据)。

## 视觉与体验审查重点

- 视觉气质：石墨黑页面、分层深灰表面、靛蓝主操作与少量暖色细节；浅色主题仍可切换比较。
- 信息重心：左侧编辑、右侧当前成果，提交后留在当前页；近期作品和灵感位于成果区下方。
- 页面分工：创作聚焦当前工作，作品库负责浏览，任务页负责状态和问题定位。
- 细节体验：模式与画幅组件、主画面尺寸、切换与确认动效、移动端阅读顺序、等待/失败/待核实状态是否清楚。开启系统减少动态效果时使用静态反馈。

用户已授权按设计实施；当前交付可以审查实际代码和真实 React 页面截图。提交防重、身份隔离、签名媒体、任务发现与轮询已有定向测试，但真实上传续传、供应商任务、实际计费和实机体验仍需相应环境验证，不能宣称完整生产验收。全站视频作品历史本轮不合并。
