# 视频作品素材交付

本目录包含五组专用插画（各 PNG + WebP）和两张演示封面，共 12 个位图文件。沿用已确认的 KKAI / `gpt-image-2` 生成资产，本轮没有重新生图。PNG 为透明母版交接，WebP 供实现按需打包；无须同时把两种格式加载进页面。

## 插画与封面

| 资产 | 像素尺寸 | 用法 |
| --- | --- | --- |
| [header.webp](header.webp) / [header.png](header.png) | 633×480 | 页头主题，桌面显示框 116×88px；不挤占作品主内容 |
| [empty.webp](empty.webp) / [empty.png](empty.png) | 354×300 | 首次没有作品；主空态约 140×123px，contain |
| [processing.webp](processing.webp) / [processing.png](processing.png) | 304×300 | 排队/生成中辅助插画，配真实阶段文字；不是百分比进度条 |
| [failed.webp](failed.webp) / [failed.png](failed.png) | 352×264 | 生成失败，配公开原因；不代表已退款 |
| [expired.webp](expired.webp) / [expired.png](expired.png) | 360×264 | 后端明确媒体已失效/过期时使用；通用播放错误、可续期签名到期不使用该结论 |
| [demo/ocean.webp](demo/ocean.webp) | 960×540 | 仅设计/固定视觉夹具用的海景示例封面 |
| [demo/coupe.webp](demo/coupe.webp) | 960×540 | 仅设计/固定视觉夹具用的汽车示例封面 |

四种状态由同一组 1536×1024 原图切分并透明化；两张示例封面的原始生成图为 1536×864，交付 WebP 为 960×540。母版与交付文件尺寸不要混淆。每个交付文件的哈希和源名见 [资源清单](../design/manifest.json)。

示例封面必须标明“示例封面”，放在 `demo/` 防止误导入生产默认图。正式页面从任务获授权媒体摘要获得真实封面；缺图时用现有矢量视频图标和中性底，不用示例图补位，也不在浏览器为整页视频抓帧。

## 工具图标

原型使用 Lucide 描述视觉意图；项目正式实现统一使用已有 `@hugeicons/core-free-icons` + `HugeiconsIcon`。不能因原型使用 Lucide 就新增依赖，也不需要为这些工具生成 PNG 切图。

| 语义 | 视觉大小 | 交互规范 |
| --- | --- | --- |
| 播放/查看作品 | 14–20px；封面圆钮桌面约 31px、手机约 43px | 主入口；触屏命中区至少 44×44px；焦点可见 |
| 下载 | 14–16px | 次级工具；仅媒体可下载时可用，错误可重试 |
| 复制任务 ID | 12–16px | 独立目标；实际复制完整值，成功后反馈；不嵌套在播放按钮中 |
| 任务详情 | 14–16px | 与下载同组；明确可访问名称和 Tooltip |
| 搜索/无结果 | 16px / 26px | 无结果图标不能替代文字和重置操作 |
| 重置/重新加载 | 16px | 区分重置筛选与重试媒体，不发起新生成 |
| 成功/进行中/失败 | 13–16px | 必须配状态文本，不靠颜色判断 |
| 关闭/返回 | 16px | 独立按钮；键盘、触屏均可操作 |

各图标按语义选用已安装版本中的对应图标，线宽与尺寸统一，继承前景色。实心播放三角与线性工具图标的差别可保留，不能混入另一套视觉风格。Hover、focus-visible、pressed、disabled、loading 都需实现。

## 加载与适配

- 插画透明背景用 `object-fit: contain`；封面入口保持 16:9、预设宽高，避免图片加载引发布局跳动。实际视频播放用 contain，长竖屏不裁断主体。
- 手机成功封面铺满卡片，状态图区域约 2.3:1；不能将小状态图强行撑成全幅照片。
- 装饰图使用空 alt，状态由旁边文字表达。内容封面的可访问名称由“查看作品 + 模型/任务信息”提供，避免重复朗读。
- 列表封面懒加载；只为打开的作品挂载视频。静态插画随构建打包，不引用设计机绝对路径、不在生产调用生图服务。
- 深浅色复用同一组透明资产，检查边缘、阴影和背景对比。暗色亮边不得用一层不透明白底掩盖。
- 插画不是错误恢复机制；按真实状态选择资产，数据/权限失败遵循后端和前端契约。
