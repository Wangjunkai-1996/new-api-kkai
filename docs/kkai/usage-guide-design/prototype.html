接入遇到问题？

点击后没有打开 CC Switch

先安装并运行 CC Switch，允许浏览器打开外部应用，然后点击“再次打开”。已创建的 Key 会保留，无需重复创建，也可以选择手动配置。

“不设置 Key 额度上限”是什么意思？

该 Key 不设置独立的消费额度，仍会正常扣除账户余额或套餐用量。你可以随时在 API 密钥中修改额度、停用或删除它。

Claude Code 和 Claude Desktop 是同一个工具吗？

它们是不同的使用入口。本页 Claude 快捷配置面向 Claude Code；Claude Desktop 的下载与接入说明单独提供，配置后按对应教程启用或重启。

配置好了，但是请求失败

401：检查 Key 是否完整、有效；403：检查分组与模型权限；余额不足：充值或检查套餐；模型不可用：重新选择当前分组可用的模型。更具体的原因可以在使用记录中查看。

我已经有 Key，还要新建吗？

不需要。可以从 API 密钥页面选择自己的已有 Key，再进行配置。本向导不会修改旧 Key 的名称、额度或权限。

网页说创建结果未确认，怎么办？

网络中断时，Key 可能已经创建。先去 API 密钥页面核对，不要连续点击新建。已创建的 Key 也不会因为退出向导被自动删除。
