## 2. 本轮已收敛的决定

1. 一个创作表单，不设“文生/图生”顶层切换。无参考时只有支持文字生成的型号可提交；有素材使用新参考集合；视频必填型号仍必须有视频。
2. 图片、视频、音频属于首版完整交付。单音频可先上传，搭配视觉素材后才可报价和生成。
3. 保留现有 `token_id`、精确 `model` 和 quote 字段；新增能力版本与 `asset_id/role/position`。同角色按从 0 连续的位置排序，不能按 asset ID 排序。
4. 图片上传用途仍是 `reference`，生成角色改为 `reference_image`；新增音频上传用途和角色 `reference_audio`。两种字段不混用。
5. 模型变化保留素材；不兼容项明确待处理，只有用户明确排除才不发送。替换失败保留旧素材；移除草稿项不能删除任务仍在使用的存储对象。
6. 报价绑定实际输入。发送前持久化原键与请求快照；受理不明只查询，不能换键重发。已落地只读 by-key 查询和视频非终态幂等记录的过期保护。
7. 前端按有效 `max_size_bytes` 包含边界检查；供应商严格 `<50 MB` 门槛先在能力配置中转换成有效整数上限。单位由后端文档明确，不能一边用 MB、一边误用 MiB。
8. 新样片与新任务复用按真实输入快照恢复。旧样片/草稿不自动转换；旧任务结果、关联、后台处理和账目不受新入口切换破坏。
9. 实际运行时有七个界面语言 `zhCN/en/fr/ru/ja/vi/zhTW`。产品文档的六基准语种必须补上已存在的繁体覆盖，不能显示裸 key。
10. 前序 `bun check -b` 工具链缺口已由实际 `bunx tsc -b --pretty false --noEmit` 检查解除；测试或 lint 成功仍不能替代类型检查。

## 3. 设计还原合同

主验收对象是**完整 Web 页面**，包括平台头部、侧栏、页标题、工作室导航、编辑器、大幅结果和近期任务。禁止只交素材区截图、用原型的模拟状态冒充真实业务，或完成布局后省略异常状态。

主基准使用 1440×1000 viewport、DPR 1、同浏览器/系统/字体、简体中文，固定一张图片/一个视频/一段音频及结果/近期任务。现有 full-page 桌面图片为 1440×1218，1218 是内容高度，不是浏览器 viewport 高度。

| 高还原要求 | 执行方式 |
| --- | --- |
| 完整构图 | 56px 顶栏、184px 侧栏、410px 编辑器、24px 双栏间距；结果保持大画面；详细 token/断点见 frontend.md |
| 主题与宽度 | 320×900、390×844、1280×900、1440×1000、1920×1080 五档默认态，深浅双主题；关键状态重点覆盖桌面与窄屏 |
| 同状态对照 | 默认、空、上传、检查、失败、组合错误、排除、替换、报价、受理不明、任务各阶段及媒体预览；原型未画出的业务状态补同体系基准 |
| 几何硬门槛 | 关键锚点 x/y/宽高误差目标 ≤2 CSS px，边框/圆角 ≤1px；区块顺序、列数、换行、操作可达必须正确 |
| 像素证据 | 先固定数据/字体，再分区生成 diff；差异率只辅助人工审查，不能掩盖错位、缺按钮或错误文案 |
| 必要偏差 | 保留真实导航、权限、账户和平台功能；提升对比度/触控面积；移除演示标记。逐项登记偏差和局部新基准，不做笼统“基本一致”豁免 |

这些是本轮拟定的团队验收标准。实施按 QA 第 3 节记录环境、容差、遮罩和偏差；不能靠放宽阈值消除失败。额外平台操作只影响其所在局部，不能借此放弃整页比例。既有全局头部为 48px、侧栏 208px，使用创作路由作用域适配到设计值，离开此路由不影响其他页面；不复制第二套平台壳。

## 4. 开发工作包与依赖

角色表示责任，不虚构真实人员、排期或已分配的生产权限。前端和后端可以在冻结的测试替身合同上并行，但真实能力验收未完成不能开放相应型号。

| 顺序 / 工作包 | 主责 / 协作 | 可审查输出 | 结束条件 |
| --- | --- | --- | --- |
| D0 合同与能力 | 后端/接入；前端、QA复核 | 精确型号矩阵、外置 adapter 源码/版本、backend.md 合同实例、未知项处理 | 能力事实和拟定字段分开；首批开放型号的数量/声音/价格/渠道条件有证据 |
| D1 媒体与有序引用 | 后端；QA | audio purpose、真实 MP3/WAV 探测、元数据证据、角色/position 规范化、样片/任务输入快照 | 组合/边界/权限测试正确；必要 schema 方案独立明确 |
| D2 请求与费用安全 | 后端；前端、QA | quote/hash、新 submit、只读恢复、视频 key 保护、插件与 adapter 投影 | 未知受理不二次派发/扣费；失效报价/旧请求拒绝；字段和顺序无丢失 |
| D3 页面骨架与组件 | 前端；设计、QA | 基于实际 React 页面与既有壳的完整深浅稿、混合引用组件、语义状态 | 先用确定性 fixture 对齐 1440 深浅基准，再覆盖断点；不能直接复制模拟 JS |
| D4 真实联调 | 前端/后端；QA | 上传/恢复/播放/错误、报价/提交/查询、新样片、任务结果 | 所有主流程和失败恢复可操作；首版三类素材均贯通；有真实媒体证据 |
| D5 质量与视觉验收 | QA；设计、代码审查 | 定向测试、类型/格式/lint、五宽度双主题、关键状态、可访问性、七语言证据 | 无未处理的阻断问题；真实适配与费用结果按实际验证范围报告 |
| D6 发布准备（后续独立范围） | 发布执行者；后端/前端 | 正式运行手册要求的产物、接口合同与迁移判断 | 仅在用户授权发布后执行；不凭本开发文档启动生产操作 |

D1/D2 与 D3 可并行，D4 依赖前后端同一合同。D3 应尽早提交完整页面对照，避免联调末尾才发现平台壳和列宽错位。每个工作包按可审查的变更提交，不用只改前端按钮宣称多模态完成。

## 5. 代码质量门槛

审查须看变更文件及受影响调用链，不只看新增页面。遵循仓库 AGENTS 与已安装 Ponytail 规则，优先复用 Uppy、React Query、RHF/Zod、Zustand、Base UI、既有媒体与任务/计费机制。

| 维度 | 必须满足 | 阻断例子 |
| --- | --- | --- |
| 结构 | 组件按业务边界拆分；单一草稿事实来源；不新增无用途通用层 | 多份引用数组同步补丁、复制上传协议、复制平台壳、收费请求由 Effect 自动触发 |
| 类型与契约 | 新响应在边界校验；前后端合同一致；0/false 不丢；required position 能识别缺失 | `any` 掩盖合同、强制断言猜类型、未实现字段静默透传/忽略 |
| 用户数据 | 换模型/替换/刷新/晚到响应均不覆盖用户意图；owner/session 隔离 | 截断素材、静默排除、跨账号回调污染、删除被任务引用的对象 |
| 并发与账务 | 使用既有事务/锁/回执/账务状态机；明确未受理才允许新付费意图 | 不明受理重发、幂等键过期重复派发、重复退款、溢出负收费 |
| 安全 | 真实内容/大小/时长校验；授权访问；资源限制；日志脱敏 | 只看扩展名、信任客户端 ready、任意 URL 拉取、签名或密钥泄露 |
| 测试 | 明确输入和行为断言；复用现有 Vitest/RTL、Go require/assert；只跑受影响范围 | 只测私有常量/实现细节、随机大循环、sleep 计时、用 mock 宣称真实生成通过 |
| 视觉与可访问性 | 完整设计对照；键盘/焦点/触控/读屏/缩放可用；全部运行时语言完整 | 只验桌面深色、遮罩关键区域、无素材试听、长文撑破布局、裸翻译 key |

所有影响本需求的阻断缺陷必须修复后才可标记完成；不能以工期或像素平均差异小为由跳过。小差异需有具体位置、原因和处理结果，禁止用一个整体“高还原”结论代替证据。

## 7. 验证与本次交付边界

本节原先记录的是前序文档阶段的 L0 检查范围；当前实现、真实定向测试、TS/lint/i18n/视觉证据及未验证边界见[实现与验收记录](implementation-qa.md)。全量套件、真实上游/外置 adapter 联调和生产操作仍未验证，不能据本地证据宣称已上线。

后续代码验证按实际风险选择最小足够范围，命令见 frontend.md / backend.md / qa.md。没有 targeted typecheck 不能悄悄改跑全项目；全套命令或耗时未知/超过五分钟按用户规则先说明并取得授权。发布或 schema 的必需门禁按对应正式手册执行，不把普通代码检查等同上线证明。

最终实现报告至少给出：实际修改、精确型号/组合、定向命令及结果、全量是否运行、完整页面截图与偏差处理、真实媒体/接入/费用证据、未验证范围。只完成文档、静态页面或 mock 测试时必须按该阶段报告。
