## 可操作的设计

- 添加三种示例素材；查看素材；移除并撤销。
- 切换模型，查看不支持的素材，明确排除或恢复。
- 修改描述、时长、分辨率、画幅和声音；查看组合限制与费用状态。
- 查看近期任务，复用设置，新建草稿，切换深浅主题。
- 确认后展示模拟排队状态。

图片为已有示例静帧，视频和音频预览展示控件位置，不加载实际视频或音频。不上传、不创建真实任务、不扣费；刷新恢复初始示例。模型能力与额度是设计候选，实际开放条件以产品方案中的供应商核实与接入验收为准。
